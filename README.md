# Bridge

Customer Engagement Platform mockup — campaigns, customers, inbox, leads, analytics, and WhatsApp Business workflows for enterprise teams.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Biome

## Notes

- Demo / mock data only — no production backend required for the UI walkthrough.
- Public branding is company-agnostic (`Bridge`).
